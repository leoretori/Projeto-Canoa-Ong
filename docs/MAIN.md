## 🤖 Papéis no Squad (Subagents Antigravity)
- **Subagent 1 (Infra/Líder):** AWS SAM (`template.yaml`), Cognito, API Gateway, Budget Alert (US$ 1,00) e guardião de contratos.
- **Subagent 2 (Front-End/UI):** React Native + Expo + Expo Router + NativeWind (Web/Mobile). Sem regras de negócio.
- **Subagent 3 (Back-End/API):** AWS Lambdas Python 3.12+, validação estrita com Pydantic v2.
- **Subagent 4 (Banco de Dados):** Amazon DynamoDB, Single Table Design com Boto3 e travas de concorrência.
- **Subagent 5 (QA & Testes):** Testes unitários com pytest, simulação de concorrência e estresse.
- **Subagent 6 (Doc Acadêmica):** Relatório técnico, procedimentos de teste e manual de uso seguro.
